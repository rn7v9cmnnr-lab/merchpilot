# MerchPilot

Code für die MerchPilot-Chrome-Erweiterung (Amazon Merch on Demand).
`bundle.js` wird von der installierten Hülle bei jedem Aufruf von merch.amazon.com geladen.
Enthält keine Konto- oder Verkaufsdaten.

Schriften: Anton, Bebas Neue, Pacifico, Permanent Marker, Oswald, Archivo Black – SIL Open Font License.
